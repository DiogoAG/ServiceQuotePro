# **App Name**: ServiceQuotePro

## Core Features:

- User Authentication & Dashboard: Secure contractor login/registration and a dashboard overview of quotes.
- Business Profile Management: Configure contractor's business details including name, license, logo, default tax, and labor rates.
- Client Management: Add, edit, and select client information to streamline quote creation.
- Quote Builder: A guided interface to add work scope items, quantities, unit prices, notes, and specific fields for painting jobs.
- Automatic Pricing Calculation: Real-time calculation of total costs, labor, and taxes based on entered items and business rates.
- AI-Assisted Scope Description Tool: Generates clear, professional work scope descriptions for services based on brief input from the contractor.
- Quote Review & PDF Export: Provides a final summary for review and exports the professional client quote as a PDF document.

## Style Guidelines:

- Primary color: A deep, professional indigo blue (#1B4598), representing reliability and corporate integrity, providing strong contrast on a light background.
- Background color: A very light, desaturated cool grey (#F0F2F4), fostering a clean and calm working environment while maintaining harmony with the primary color.
- Accent color: A vibrant turquoise-blue (#1AC4E6), analogous to the primary but brighter, to highlight interactive elements and draw attention to calls-to-action without being overpowering.
- Headline and body font: 'Inter', a grotesque-style sans-serif for its modern, neutral, and highly readable qualities, ensuring clarity across all content.
- Use clean, professional, and easily recognizable line icons to enhance navigation and data visualization.
- Employ a modular and responsive layout, prioritizing data input clarity and quote readability on various screen sizes, with dedicated dashboards and forms.
- Implement subtle animations for transitions and feedback on user actions (e.g., successful quote generation, form submission), enhancing the user experience without distraction.
